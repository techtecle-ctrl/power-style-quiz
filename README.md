# What's Your Power Style?

A 12-question quiz that identifies how you default to winning — through
people, positioning, execution, or leverage — and names the blind spot that
comes with it.

**Live:** https://techtecle-ctrl.github.io/power-style-quiz/

Single static HTML file, no build step, no dependencies, no tracking beyond
what's documented on the page. Deployed via GitHub Pages from `index.html`.
